# VetX design system

## Overview

The clinical folder is the visual reference. Soft paper tones make text easy to find and read. A single deep-green field carries the crossed-stroke VetX mark.

## Colors

Canvas surrounds the paper surface. Ink carries headings and muted green carries secondary text. A fine line defines edges and separates related information. The two palettes respond to the system color scheme.

Use the focus color for the keyboard outline. Pair readiness colors with a localized label so color can reinforce the message.

## Typography

Instrument Serif carries the audience title. Instrument Sans carries web controls, status, and copy. The native apps use the platform typeface for body text and controls alongside Instrument Serif headings. Text can scale with the device setting.

## Layout

The masthead pairs the VetX wordmark with a language control. The folio divides into a reading panel and a mark panel at 49rem. At narrower widths and in native apps, the reading panel comes first and the mark panel follows in the same scroll flow.

## Elevation & Depth

Tonal layering and fine borders define the folio. A small shadow distinguishes the selected language on web.

## Shapes

The folio has a rounded outer edge. Its mark panel contains a fine outline and two crossing strokes. Controls share a smaller corner radius and have a minimum 48px or 48dp target.

## Components

- The language control uses each language’s own name and makes the active choice visible and accessible.
- The readiness line displays a localized status. The pending state uses an outlined dot, and the result uses a filled dot.
- The loading skeleton marks the heading’s position while the native locale loads.

The shared source lives in [design tokens](packages/design-tokens/src/index.ts), with web variables generated by `pnpm --filter @vetx/design-tokens sync-css`.
